# 🎯 Machine Learning Specialization — Coursera (by Andrew Ng)

This repository contains my completed **programming exercises and projects** from the **Machine Learning Specialization** on [Coursera](https://www.coursera.org/specializations/machine-learning-introduction), taught by **Andrew Ng** and offered by **DeepLearning.AI** and **Stanford University**.

Each folder corresponds to a specific topic or assignment from the specialization — covering supervised learning, unsupervised learning, neural networks, recommender systems, and reinforcement learning.

---

## 🧩 Repository Structure

### 📘 Supervised Learning
Foundations of regression and classification models.
- `1_Regression` — Linear Regression 
- `2_Classification` — Logistic Regression 
- `3_Regularization_Overfit_Solution` — Ridge and Lasso Regularization
- `4_DecisionTree` — Decision Trees for Classification and Regression
- `5_RandomForest` — Ensemble Learning using Random Forest
- `6_XGBoost` — Extreme Gradient Boosting implementation

---

### 🔍 Unsupervised Learning
Discovering hidden patterns and detecting anomalies.
- `1_K-Means` — Clustering using K-Means Algorithm
- `2_Anomaly_Detection` — Gaussian Model and Outlier Detection

---

### 🧠 Neural Networks
Understanding and building neural network architectures.
- `BinaryClassification` — Single-layer Neural Network for Binary Output
- `Multi-class-classification` — Multi-class Neural Network using Softmax

---

### 🎬 Recommender System
Building personalized systems for user-item interaction.
- `Collaborative Filtering` — User-Item Matrix Factorization
- `Content Based Filtering` — Feature-based Recommendation Approach

---

### 🚀 Reinforcement Learning
Applying machine learning to dynamic environments.
- `1_Lunar Lander` — Training an agent to land safely using reward-based learning

---

### 💼 Project
Applied learning through a Python mini-project.
- `pythonProject1: catalog_sales_profit.py` — Predicting catalog sales profit using Linear Regression

---

## 🧠 Key Learnings
- Core algorithms: Linear/Logistic Regression, Decision Trees, XGBoost, K-Means, Neural Networks  
- Model tuning and regularization to avoid overfitting  
- Recommender system fundamentals  
- Hands-on Reinforcement Learning basics
